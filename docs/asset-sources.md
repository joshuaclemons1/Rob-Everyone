# Asset Sources

Curated free/cheap asset packs that fit [art-style.md](art-style.md)'s
"Bright Cartoon Suburbia" direction. All CC0 (public domain — no
attribution required, fully commercial-safe) unless noted otherwise.

## Kenney — environment (confirmed good match)

All from [kenney.nl](https://kenney.nl), CC0, ship as FBX/OBJ/GLTF with
Unity import instructions.

| Pack | Use | Link |
|---|---|---|
| City Kit (Suburban) | House exteriors — the core "reuse 2–3 shells" kit for the map's house ring | [kenney.nl/assets/city-kit-suburban](https://kenney.nl/assets/city-kit-suburban) |
| Modular Buildings | Kitbash pieces if you want custom variants (e.g. a visually distinct "Good House") | [kenney.nl/assets/modular-buildings](https://kenney.nl/assets/modular-buildings) |
| City Kit (Roads) | Streets/sidewalks connecting the houses | [kenney.nl/assets/city-kit-roads](https://kenney.nl/assets/city-kit-roads) |
| City Kit (Commercial) | Possible source for the police station / fenced compound | [kenney.nl/assets/city-kit-commercial](https://kenney.nl/assets/city-kit-commercial) |

## Characters — Quaternius Ultimate Animated Character Pack (chosen)

[quaternius.com/packs/ultimatedanimatedcharacter.html](https://quaternius.com/packs/ultimatedanimatedcharacter.html)
— 50+ animated low-poly characters, CC0, FBX/OBJ/Blend. Use this for
homeowners and police; pick/reskin specific characters from the set for
each role (and player skins, later, at Stage 5–6).

Not from Kenney, but pairs fine visually with the Kenney environment kits
above — both are clean low-poly/CC0, and mixing sources here is normal for
free asset workflows.
